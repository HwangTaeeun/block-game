# 멍때리기 게임 포털 (Auto Game Portal)

켜 놓고 구경만 해도 알아서 플레이되는 한 화면짜리 게임 모음입니다. 빌드 없이 브라우저에서 `index.html`을 열면 됩니다.
그래픽과 효과음은 모두 코드(Canvas, WebAudio)로 만들었고 외부 이미지·소리·상표는 없습니다.

## 게임 목록

| 게임 | 파일 | 설명 |
|---|---|---|
| 자동 스네이크 | `games/snake.html` | 해밀턴 사이클 기반이라 절대 안 죽는 뱀. 지름길과 변덕이 있고 방향을 꺾을 때 키 소리가 남 |
| 벽돌깨기 | `games/breakout.html` | 200레벨, 자동/수동 모드. 아래에 규칙 정리 |
| 자동 퐁 | `games/pong.html` | 두 AI의 랠리, 길어질수록 빨라짐 |
| 자동 블록쌓기 | `games/tetris.html` | 모든 위치를 계산해 줄을 지우는 AI, 가끔 망설임 |
| 자동 날개새 | `games/flappy.html` | 파이프 사이를 알아서 통과, 안 부딪힘 |
| 지렁이 대결 | `games/worms.html` | 4마리가 사과 경쟁, 막히면 쓰러졌다가 다시 태어남 |
| 생명 게임 | `games/life.html` | 세포 자동자, 멈추면 새 생명 투입 |

공통: 위쪽 바에 속도 슬라이더와 효과음 버튼(브라우저 정책상 한 번 눌러야 켜짐)이 있습니다.

## 구조

```
index.html          포털 첫 화면
common.css/js       공용 스타일, 상단 바, 효과음, 고정 간격 루프
games/*.html        게임 (각각 단독 실행 가능)
games/breakout_levels.js   벽돌깨기 1~200레벨 배치 생성기 (레벨 번호가 같으면 항상 같은 모양)
```

## 벽돌깨기 규칙

### 조작
- **자동 모드(기본)**: 패들이 알아서 움직입니다. 위쪽 바 버튼으로 수동 모드와 전환.
- **수동 모드**: 좌우 방향키로 패들 이동, 스페이스 또는 화면 클릭/터치로 발사. 목숨 3개.
- **P**: 일시정지 "Bathroom Break" / **O**: 일시정지 "Meal Break". 같은 키를 다시 누르면 재개.
- 주소 뒤에 `?level=N`을 붙이면 N레벨부터 시작 (예: `breakout.html?level=150`).

### 레벨과 난이도
- 총 200레벨. 레벨 1~9는 손으로 만든 모양, 10~200은 규칙으로 생성한 좌우 대칭 모양. 10 단위 레벨은 꽉 찬 큰 판.
- 1레벨은 벽돌 20개(2줄).
- 공 속도는 레벨마다 아주 조금씩 올라 3.8 → 약 4.9. 패들 폭은 72 → 44로 줄어듭니다.
- 레벨을 깨면 공과 패들은 그대로 두고 벽돌만 새로 깔립니다. 200레벨을 깨면 "YOU WIN!" 후 1레벨로 돌아갑니다.
- 수동 모드에서 공을 놓치면 목숨 -1, 목숨이 없으면 GAME OVER (1레벨부터).
- 공이 15초 동안 패들·벽돌에 닿지 않으면(갇힌 경우) 패들 위에서 다시 시작합니다.

### 특수 벽돌

| 벽돌 | 모양 | 효과 |
|---|---|---|
| POWER | 노랑/주황 | 깨면 파워공(불꽃)이 되어 패들에 닿을 때까지 닿는 벽돌을 전부 부수며 통과. 차례가 아닌 번호 벽돌은 못 뚫음 |
| SPEED | 파랑 | 깨면 공이 즉시 1.3배 빨라짐. 패들에 닿으면 원래 속도 |
| 번호 벽돌 (1~9) | 회색 + 숫자 | 번호 순서대로만 깨짐. 가장 작은 번호가 흰색으로 깜빡이며 "지금 차례"를 표시. 차례가 아니면 튕겨 나옴. 레벨 10부터 등장, 레벨이 오를수록 번호가 늘고 레벨 100부터는 같은 번호가 2개씩 |
| DEAD | 검정 + 빨강 | 깨면 목숨 -1 ("DEAD!"). 목숨이 없으면 GAME OVER |
| CLEAR | 초록 | 깨면 남은 벽돌이 전부 한 번에 사라지고 다음 레벨 |

POWER(6~8개)와 SPEED(3~4개)는 레벨 시작 때 일반 벽돌 중에서 정해집니다(벽돌 수가 적은 레벨은 비율에 맞춰 줄어듦).

### DEAD / CLEAR 등장 규칙
- 스테이지마다 **패들에 공이 닿은 횟수**를 새로 세고, 횟수가 정해진 간격의 배수가 되면 일반 벽돌 하나가 변합니다.
- 간격은 스테이지마다 새로 정합니다. DEAD는 10~14번마다, CLEAR는 DEAD보다 3~5번 적게(최소 5번마다) 나옵니다. 그래서 CLEAR가 더 자주 나옵니다.
- 생긴 뒤 패들에 공이 **두 번** 닿으면 사라집니다. 블럭에 남은 횟수가 표시됩니다 ("DEAD 2" → "DEAD 1").
- 번호/POWER/SPEED 벽돌은 변하지 않습니다.
- DEAD는 레벨 2부터, 살아 있는 벽돌이 3개 이상일 때, 동시에 최대 2개. 마지막 한 개가 DEAD가 되는 일은 없습니다.
- CLEAR는 살아 있는 벽돌이 4개 이상일 때, 동시에 최대 1개.
- 일반 벽돌을 다 깨면 남은 DEAD 블럭은 깨지 않아도 다음 레벨로 넘어갑니다.

### 자동 패들 (사람처럼 움직이기)
- 공이 벽돌 영역에 있는 동안은 거의 가만히 있고, 벽돌 아래로 내려오면 약 7프레임 늦게 반응합니다.
- 떨어질 위치를 ±6px 오차로 어림하고, 가속·감속하며 움직여서 가끔 살짝 지나쳤다가 되돌아옵니다.
- 패들의 어느 부분으로 칠지 벽돌을 보고 정해 겨냥합니다 (차례인 번호 벽돌 70%, CLEAR 블럭 60%, DEAD는 겨냥 안 함).
